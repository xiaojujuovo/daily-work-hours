## 每日工时 1.8.0

- 新增异常工时记录，可记录耽误时长、订单、设备、原因、多个责任方和情况说明，一天可记多条。
- 原因分类支持自定义新增、改名、排序和删除。改名同步已有记录，删除分类保留历史记录。
- 统计页新增本月异常工时，按责任方、分类和设备汇总，可分享月度总结或导出 CSV。
- 月历增加「异」标记，完整 JSON 备份包含异常记录和分类设置，兼容旧备份。
- 修复并列项目排序、英文分类名和特殊名称改名同步，修正依赖锁文件以支持全新安装。

## 下载与升级

- Android 下载 APK，使用原签名，可覆盖安装正式版或此前的异常工时测试包。
- Web 下载 ZIP，解压后部署到静态网站根目录，数据保存在当前浏览器。
- SHA-256 文件包含两个发布包的校验值。

73 项自动化测试、类型检查及全新目录依赖安装已通过。异常工时功能已由作者在安卓手机测试通过。
