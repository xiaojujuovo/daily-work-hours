# 每日工时网页版 1.6.0 部署说明

本版本只提供可部署的静态网页包，由你自行选择托管服务。安卓安装包与网页文件包分别使用。

## 部署已有网页包

1. 下载并解压 `daily-work-hours-web-1.6.0.zip`。
2. 将解压出的全部文件上传到你自己的静态网站服务，确保 `index.html` 位于网站根目录，保留 `_expo/` 下的文件及目录结构。
3. 通过 HTTP 或 HTTPS 网址打开，正式使用建议 HTTPS。不要直接双击 `index.html`；脚本使用网站根目录路径，当前包应部署在独立域名或子域名的根目录。

不需要应用服务器、数据库、账号服务或环境变量。网站的访问权限由你使用的托管服务配置。

## 从源码构建

```powershell
npm.cmd ci
npm.cmd run build:web
npm.cmd run preview:web
```

`dist/` 为静态网站输出。本机预览默认地址为 `http://127.0.0.1:8765`；本机预览脚本只提供静态文件，不接收工时数据。

## 数据与平台

工时、工资、调休和设置都保存在当前浏览器的本地存储中，不发送给部署服务器。服务器只提供页面与静态资源，页面的内容安全策略禁止 API 连接。

不同浏览器、设备和网址的数据互相独立。清除网站数据或关闭无痕窗口可能清除记录，请定期在设置中下载完整 JSON 备份。安卓与网页通过备份文件手动互通，不自动同步。

网页版没有下班提醒功能；安卓保留提醒；不支持 iOS 应用。
